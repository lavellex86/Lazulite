# Home

Welcome to the Lazulite documentation! Here you'll learn all about using the `Lavelle.Lazulite` library and its attached scientific computing stack.

To get started, check out [the-basics.md](lazulite-documentation/the-basics.md "mention") of computing with Lazulite. Once you're familiar with the framework, you can reference the [Lazulite API Reference](https://app.gitbook.com/s/8PijDWGVHzmzdSL0TKky/lazulite-api-reference "mention") for further detail.

To learn more about the `Lavelle.Linalg32` library, check out the [Linalg32 API Reference](https://app.gitbook.com/s/8PijDWGVHzmzdSL0TKky/linalg32-api-reference "mention").

To learn more about the `Lavelle.Calc32` library, check out the [Calc32 API Reference](https://app.gitbook.com/s/8PijDWGVHzmzdSL0TKky/calc32-api-reference "mention").
